# আইন লেখার নিয়ম (JSON ফাইল)

অ্যাপের **আইন ও বিভাগ ডাটাবেসে নেই**। সব আইন এই ফোল্ডারের JSON ফাইলে থাকে এবং APK-র ভেতরে ঢুকে যায়। তাই আইন পড়তে ইন্টারনেট লাগে না, আর Supabase-এর free সীমার ওপর কোনো চাপ পড়ে না।

```
content/
  categories.json        বিভাগের তালিকা (২৮টি তৈরি আছে)
  laws/
    _template.json       খালি নমুনা (অ্যাপে আসে না)
    penal-code-1860.json একটা আইন = একটা ফাইল (ফাইলের নাম = slug)
```

## নতুন আইন যোগ করার ধাপ (ফোন থেকেই)

1. GitHub-এ রিপো খুলুন → `content/laws` → **Add file → Create new file**।
2. নাম দিন `আইনের-slug.json`, যেমন `penal-code-1860.json`। শুধু ইংরেজি ছোট হাতের অক্ষর, সংখ্যা ও `-` চলবে।
3. `_template.json`-এর লেখা কপি করে বসান এবং নিজের তথ্য দিন। `"status": "published"` করুন।
4. **Commit changes** চাপুন।
5. **Actions → Build Android APK → Run workflow** দিন। ভুল থাকলে লাল হবে এবং log-এ ফাইলের নাম ও কোন ঘর ভুল লেখা থাকবে। ঠিক করে আবার চালান।
6. নতুন APK নামিয়ে install করুন।

> `"status": "draft"` লিখলে ফাইলটি অ্যাপে আসে না। অর্ধেক কাজ রাখতে এটা কাজে লাগে।

## ফাইলের গঠন

```json
{
  "slug": "penal-code-1860",
  "status": "published",
  "category": "criminal-law",
  "title": { "bn": "দণ্ডবিধি, ১৮৬০", "en": "The Penal Code, 1860" },
  "act_number": "১৮৬০ সনের ৪৫ নং আইন",
  "year": 1860,
  "law_status": "in_force",
  "summary": { "bn": "সংক্ষেপে আইনটি কী নিয়ে", "en": "" },
  "keywords": ["চুরি", "খুন", "theft"],
  "source": {
    "name": "bdlaws.minlaw.gov.bd",
    "url": "https://bdlaws.minlaw.gov.bd/",
    "last_verified": "2026-10-26"
  },
  "sections": [
    {
      "no": "378",
      "chapter": { "bn": "অধ্যায় ১৭", "en": "Chapter XVII" },
      "heading": { "bn": "চুরি", "en": "Theft" },
      "text": { "bn": "ধারার মূল পাঠ", "en": "" },
      "explain": { "bn": "সহজ ভাষায় ব্যাখ্যা", "en": "" },
      "punishment": { "bn": "শাস্তি", "en": "" }
    }
  ]
}
```

| ঘর | লাগবে? | মানে |
|---|---|---|
| `slug` | হ্যাঁ | ফাইলের নামের সাথে হুবহু মিলতে হবে |
| `category` | হ্যাঁ | `categories.json`-এর যেকোনো `slug` |
| `title` | হ্যাঁ | অন্তত একটি ভাষা; দুটোই দিলে ভালো |
| `law_status` | না | `in_force` (কার্যকর), `amended` (সংশোধিত), `repealed` (রহিত) |
| `source` | খুব ভালো | সরকারি উৎস ও শেষ যাচাইয়ের তারিখ। না দিলে সতর্কবার্তা আসে। `url` অবশ্যই `https://` দিয়ে |
| `keywords` | না | সার্চে খুঁজে পাওয়ার অতিরিক্ত শব্দ |
| `sections[].no` | হ্যাঁ | ধারা নম্বর (প্রতিটি আলাদা) |
| `sections[].text` | হ্যাঁ | ধারার মূল পাঠ |
| `sections[].chapter` | না | একই অধ্যায়ের ধারাগুলোর ওপর একবার শিরোনাম দেখায় |
| `explain`, `punishment`, `heading` | না | ফাঁকা রাখলে অ্যাপে দেখায় না |

ধারার ক্রম = ফাইলে যে ক্রমে লিখবেন সেই ক্রম।

## লেখার সময় সাধারণ ভুল

- সব লেখা `"` (ডবল কোটেশন) এর ভেতরে; শেষ আইটেমের পরে `,` দেবেন না।
- লেখার ভেতরে `"` লাগলে `\"` লিখুন। নতুন লাইন দিতে `\n` লিখুন।
- বাংলা অংশ না থাকলে ফাঁকা রাখুন (`""` বা পুরো ঘর বাদ)। অ্যাপ ইংরেজি দেখিয়ে "অনুবাদ নেই" লিখে দেবে।

## সহজ পথ: সাধারণ লেখা থেকে JSON (`laws:import`)

JSON হাতে লেখা কঠিন মনে হলে সাধারণ লেখায় আইন সাজিয়ে একটা কমান্ড চালান। লেখা **অবিকল** থাকে, কিছু বদলায় না।

১. `content/import/penal-code-1860.txt` নামে ফাইল বানান (ফোল্ডার না থাকলে নিজেই হয়ে যাবে):

```
slug: penal-code-1860
category: criminal-law
status: published
title.bn: দণ্ডবিধি, ১৮৬০
title.en: The Penal Code, 1860
act_number: ১৮৬০ সনের ৪৫ নং আইন
year: 1860
source.name: bdlaws.minlaw.gov.bd
source.url: https://bdlaws.minlaw.gov.bd/
source.last_verified: 2026-10-26
keywords: চুরি, খুন, theft

@@ অধ্যায় ১৭ | Chapter XVII
§ 378 | চুরি | Theft
ধারার বাংলা পাঠ, যত লাইন লাগে।

নতুন অনুচ্ছেদের জন্য একটা ফাঁকা লাইন।
--en
English text, if you have it.
--explain
সহজ ভাষায় ব্যাখ্যা।
--punishment
শাস্তি।
```

| চিহ্ন | মানে |
|---|---|
| `key: value` (ওপরে) | আইনের তথ্য (ওপরের টেবিলের ঘরগুলো) |
| `@@ বাংলা \| English` | এর পরের ধারাগুলোর অধ্যায়। শুধু `@@` লিখলে অধ্যায় বন্ধ |
| `§ নম্বর \| শিরোনাম(বাংলা) \| শিরোনাম(English)` | নতুন ধারা শুরু |
| (কোনো চিহ্ন ছাড়া লেখা) | ধারার বাংলা পাঠ |
| `--en`, `--explain`, `--explain.en`, `--punishment`, `--punishment.en` | এর পরের লেখা ওই ঘরে যাবে |

২. Codespace-এর terminal-এ: `npm run laws:import -- content/import/penal-code-1860.txt`
৩. ভুল থাকলে লাইন নম্বরসহ বলে দেবে এবং কিছু লিখবে না। ঠিক থাকলে `content/laws/penal-code-1860.json` তৈরি হবে।
৪. Commit, push, তারপর APK বানান।

## প্রথম কোন কোন আইন (পরামর্শ)

জমি ও সম্পত্তির অ্যাপ হিসেবে প্রথমে এই ৫টি দিয়ে শুরু করা ভালো। প্রতিটির **বর্তমান সংশোধিত রূপ** bdlaws.minlaw.gov.bd থেকে দেখে নিন, আমি নিজের স্মৃতি থেকে ধারা লিখব না।

1. দণ্ডবিধি, ১৮৬০ (ফৌজদারি)
2. রাষ্ট্রীয় অধিগ্রহণ ও প্রজাস্বত্ব আইন, ১৯৫০ (ভূমি)
3. সম্পত্তি হস্তান্তর আইন, ১৮৮২ (সম্পত্তি হস্তান্তর)
4. রেজিস্ট্রেশন আইন, ১৯০৮ (সম্পত্তি হস্তান্তর)
5. মুসলিম পারিবারিক আইন অধ্যাদেশ, ১৯৬১ (পারিবারিক/উত্তরাধিকার)

## অনেক আইন একসাথে

কাগজ/PDF/ওয়েবসাইট থেকে কপি করা লেখা আমাকে (Claude) দিন। আমি লেখাটা অবিকল রেখে শুধু JSON-এর ছাঁচে সাজিয়ে দেব। আমি নিজের মনে কোনো ধারা বানাব না বা বদলাব না। প্রতিটি আইন সরকারি উৎসের সাথে আপনি মিলিয়ে নেবেন, তারপর `published` করবেন।

```
npm run laws
```
ভুল থাকলে ফাইলের নাম ও ঘরসহ ছাপা হবে। ঠিক থাকলে `public/data`-তে অ্যাপের ফাইল তৈরি হয়।

# জমির ক্যালকুলেটরের তথ্য (`content/land/`)

ক্যালকুলেটরের মাপ, হার ও পরিভাষা ডাটাবেসে নয়, এই তিনটি ফাইলে। বদলাতে হলে ফাইল সম্পাদনা → Commit → **Build Android APK**। ভুল থাকলে build লাল হয়ে বলে দেয় কোন ঘরে।

| ফাইল | কী আছে | কীভাবে বদলাবেন |
|---|---|---|
| `units.json` | বর্গফুট, বর্গমিটার, শতক, একর, হেক্টর, দৈর্ঘ্যের একক (ফুট, হাত, গজ, মিটার, ইঞ্চি) এবং **এলাকাভেদে কাঠা/বিঘার মাপ** | `regions`-এ নতুন আইটেম যোগ করুন: `katha_sqft` (১ কাঠা কত বর্গফুট) ও `katha_per_bigha` (১ বিঘায় কত কাঠা) |
| `costs.json` | রেজিস্ট্রেশন/হস্তান্তর খরচের হার | নিচে দেখুন |
| `glossary.json` | খতিয়ান, দাগ, মৌজা, নামজারি ইত্যাদির সংজ্ঞা | `terms`-এ নতুন আইটেম যোগ করুন |

## কেন খরচের হার এখন ফাঁকা

হার প্রায়ই বদলায় এবং এলাকাভেদে আলাদা। ভুল হার দেখালে ব্যবহারকারীর ক্ষতি হতে পারে, তাই আমি নিজের স্মৃতি থেকে কোনো হার বসাইনি। `status` এখন `"draft"`, আর অ্যাপে খরচ ট্যাব বলছে "হার এখনো যোগ করা হয়নি"।

চালু করতে: সরকারি বিজ্ঞপ্তি/ওয়েবসাইট থেকে হার মিলিয়ে `costs.json` এভাবে লিখুন, তারপর build:

```json
{
  "status": "published",
  "as_of": "2026-10-26",
  "source": { "name": "যে সরকারি নথি/ওয়েবসাইট থেকে নিলেন", "url": "https://..." },
  "items": [
    { "id": "stamp", "label": { "bn": "স্ট্যাম্প শুল্ক", "en": "Stamp duty" }, "kind": "percent", "value": 1.5 },
    { "id": "fee",   "label": { "bn": "নিবন্ধন ফি", "en": "Registration fee" }, "kind": "fixed", "value": 500 }
  ]
}
```
`kind: "percent"` হলে দলিল মূল্যের শতাংশ; `"fixed"` হলে নির্দিষ্ট টাকা। এখানে `1.5` ও `500` শুধু নমুনা, আসল হার নয়। `published` লিখলে `as_of` (কবে যাচাই করেছেন) ও `source.name` না দিলে build ব্যর্থ হয়।

## কাঠা ও বিঘার মাপ নিয়ে সতর্কতা

`units.json`-এ এখন দুটি প্রচলিত মাপ আছে: (১) ১ কাঠা = ৭২০ বর্গফুট, ১ বিঘা = ২০ কাঠা; (২) ১ বিঘা = ৩৩ শতক। এলাকাভেদে আরও মাপ আছে। আপনার এলাকার মাপ স্থানীয় ভূমি অফিস বা পুরোনো দলিল থেকে নিশ্চিত হয়ে `regions`-এ যোগ করুন। ব্যবহারকারীও "নিজের মাপ দিন" থেকে নিজে লিখতে পারেন।
