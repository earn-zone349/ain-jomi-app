# আইন লেখার নিয়ম (JSON ফাইল)

অ্যাপের **আইন ও বিভাগ ডাটাবেসে নেই**। সব আইন এই ফোল্ডারের JSON ফাইলে থাকে এবং APK-র ভেতরে ঢুকে যায়। তাই আইন পড়তে ইন্টারনেট লাগে না, আর Supabase-এর free সীমার ওপর কোনো চাপ পড়ে না।

```
content/
  categories.json        বিভাগের তালিকা (২৮টি তৈরি আছে)
  laws/
    _template.json       খালি নমুনা (অ্যাপে আসে না)
    penal-code-1860.json একটা আইন = একটা ফাইল (ফাইলের নাম = slug)
```

## নতুন আইন যোগ করার ধাপ (ফোন থেকেই)

1. GitHub-এ রিপো খুলুন → `content/laws` → **Add file → Create new file**।
2. নাম দিন `আইনের-slug.json`, যেমন `penal-code-1860.json`। শুধু ইংরেজি ছোট হাতের অক্ষর, সংখ্যা ও `-` চলবে।
3. `_template.json`-এর লেখা কপি করে বসান এবং নিজের তথ্য দিন। `"status": "published"` করুন।
4. **Commit changes** চাপুন।
5. **Actions → Build Android APK → Run workflow** দিন। ভুল থাকলে লাল হবে এবং log-এ ফাইলের নাম ও কোন ঘর ভুল লেখা থাকবে। ঠিক করে আবার চালান।
6. নতুন APK নামিয়ে install করুন।

> `"status": "draft"` লিখলে ফাইলটি অ্যাপে আসে না। অর্ধেক কাজ রাখতে এটা কাজে লাগে।

## ফাইলের গঠন

```json
{
  "slug": "penal-code-1860",
  "status": "published",
  "category": "criminal-law",
  "title": { "bn": "দণ্ডবিধি, ১৮৬০", "en": "The Penal Code, 1860" },
  "act_number": "১৮৬০ সনের ৪৫ নং আইন",
  "year": 1860,
  "law_status": "in_force",
  "summary": { "bn": "সংক্ষেপে আইনটি কী নিয়ে", "en": "" },
  "keywords": ["চুরি", "খুন", "theft"],
  "source": {
    "name": "bdlaws.minlaw.gov.bd",
    "url": "https://bdlaws.minlaw.gov.bd/",
    "last_verified": "2026-10-26"
  },
  "sections": [
    {
      "no": "378",
      "chapter": { "bn": "অধ্যায় ১৭", "en": "Chapter XVII" },
      "heading": { "bn": "চুরি", "en": "Theft" },
      "text": { "bn": "ধারার মূল পাঠ", "en": "" },
      "explain": { "bn": "সহজ ভাষায় ব্যাখ্যা", "en": "" },
      "punishment": { "bn": "শাস্তি", "en": "" }
    }
  ]
}
```

| ঘর | লাগবে? | মানে |
|---|---|---|
| `slug` | হ্যাঁ | ফাইলের নামের সাথে হুবহু মিলতে হবে |
| `category` | হ্যাঁ | `categories.json`-এর যেকোনো `slug` |
| `title` | হ্যাঁ | অন্তত একটি ভাষা; দুটোই দিলে ভালো |
| `law_status` | না | `in_force` (কার্যকর), `amended` (সংশোধিত), `repealed` (রহিত) |
| `source` | খুব ভালো | সরকারি উৎস ও শেষ যাচাইয়ের তারিখ। না দিলে সতর্কবার্তা আসে। `url` অবশ্যই `https://` দিয়ে |
| `keywords` | না | সার্চে খুঁজে পাওয়ার অতিরিক্ত শব্দ |
| `sections[].no` | হ্যাঁ | ধারা নম্বর (প্রতিটি আলাদা) |
| `sections[].text` | হ্যাঁ | ধারার মূল পাঠ |
| `sections[].chapter` | না | একই অধ্যায়ের ধারাগুলোর ওপর একবার শিরোনাম দেখায় |
| `explain`, `punishment`, `heading` | না | ফাঁকা রাখলে অ্যাপে দেখায় না |

ধারার ক্রম = ফাইলে যে ক্রমে লিখবেন সেই ক্রম।

## লেখার সময় সাধারণ ভুল

- সব লেখা `"` (ডবল কোটেশন) এর ভেতরে; শেষ আইটেমের পরে `,` দেবেন না।
- লেখার ভেতরে `"` লাগলে `\"` লিখুন। নতুন লাইন দিতে `\n` লিখুন।
- বাংলা অংশ না থাকলে ফাঁকা রাখুন (`""` বা পুরো ঘর বাদ)। অ্যাপ ইংরেজি দেখিয়ে "অনুবাদ নেই" লিখে দেবে।

## অনেক আইন একসাথে

কাগজ/PDF/ওয়েবসাইট থেকে কপি করা লেখা আমাকে (Claude) দিন। আমি লেখাটা অবিকল রেখে শুধু JSON-এর ছাঁচে সাজিয়ে দেব। আমি নিজের মনে কোনো ধারা বানাব না বা বদলাব না। প্রতিটি আইন সরকারি উৎসের সাথে আপনি মিলিয়ে নেবেন, তারপর `published` করবেন।

## নিজের কম্পিউটারে/Codespace-এ যাচাই

```
npm run laws
```
ভুল থাকলে ফাইলের নাম ও ঘরসহ ছাপা হবে। ঠিক থাকলে `public/data`-তে অ্যাপের ফাইল তৈরি হয়।
